모아카 개인정보처리방침

시행일: 2026년 10월 9일

1. 수집 및 전송

앱은 회원가입, 사용자 분석 또는 위치 추적 기능을 제공하지 않으며 프로필과 컬렉션 데이터를 운영자 서버로 전송하지 않습니다. 모바일 앱은 Google AdMob 하단 배너 광고를 사용합니다. 광고 제공 및 부정 사용 방지를 위해 Google SDK가 IP 주소, 기기 식별자, 광고 상호작용 및 진단 정보를 처리할 수 있습니다. 자세한 사항은 Google 개인정보처리방침을 확인해 주세요. 웹 및 독립 실행 HTML에서는 AdMob을 사용하지 않습니다.

2. 기기 내부 데이터

사용자가 입력한 프로필 사진, 섬 이름, 주민 대표 이름, 한마디, 보유 수량, 즐겨찾기와 메모는 사용자의 기기에만 저장됩니다.

3. 백업과 복원

백업하기를 사용하면 JSON 파일이 생성됩니다. 모바일 앱에서는 운영체제 파일 저장 화면에서 사용자가 선택한 위치에 저장됩니다. 복원하기는 파일 선택 화면에서 JSON 백업을 선택하며, 검증이 완료된 백업의 프로필과 카드 기록으로 현재 데이터를 교체합니다. 앱이 저장 위치를 자동 선택하거나 사본을 운영자에게 보내지 않습니다.

4. 삭제

설정의 사용자 데이터 초기화로 앱 내부 사용자 데이터를 삭제할 수 있습니다. 사용자가 외부에 저장한 백업 파일은 해당 저장 위치에서 직접 삭제해야 합니다.

5. 문의

개인정보 및 앱 이용 문의는 앱 메뉴의 문의하기 또는 baeka.nojob@gmail.com을 이용해 주세요.

6. 변경

방침이 변경되면 이 페이지의 내용과 시행일을 갱신합니다.
